# Concrete asks
- Push premium harder. Adam says "eyes don't know where to look — colour is confusing." Diagnose where the eye-flow breaks and fix it. Possibly the green Business avatar circle competing with the prayer banner sun and the timer — too many tinted accents on one screen. Reduce to one or two intentional color accents per screen.
- Adam's avatar (top-right of screen): must show **black hair + black beard**. The Tapback API is deterministic on a seed string and you can pass `?color={1-12}`. Try seeds like `adam`, `adamlashin`, `lashin` etc. until you land on a black-hair-black-beard memoji.
- Domain icons on tasks/cards: **stop using memojis for tasks**. Use a colored circle + emoji pattern (e.g. peach circle + 🚀 for Business, mint + 🕌 for Religion). The memoji is reserved for the *user* (Adam) only.
- Bottom nav: the last two icons don't fit. Pick icons that match the system more cohesively. Tabs are: NOW · TODAY · DOMAINS · VISIONS.
- Harmony: the idle and in-flow variants currently have different layouts (nav bar position, hierarchy). Make them obviously the same screen in two states — same chrome, only the focal content morphs.
