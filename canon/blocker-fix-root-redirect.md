Root redirect was broken because `page.tsx` read from `useDoIt.getState()` before Zustand's persist middleware rehydrated (skipHydration:true, StoreHydrator only runs inside (shell)/layout.tsx). Fixed by reading directly from the Zustand localStorage key `do-it-state` via JSON parse, with a secondary fallback key `do-it-onboarding-complete`. Added a 1.5s timeout fallback to force /onboarding if router.replace hangs. `completeOnboarding()` now writes the fallback key too. No store dependency in the root route.
