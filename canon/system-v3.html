do it · system v3

Calibrated foundation. v2 tokens preserved + board/-driven compositional primitives. Each screen gets its own hero treatment + dimensional illustration + texture — every page feels different while the system holds.

palette law. white, pink, green, black, blue. nothing else. amber, orange, red, purple, yellow are forbidden. tints below are calibrated from board/.

composition law. every priority surface earns a hero gradient + texture noise + one dimensional element. cards stay generous (rounded-24/30) and breath comes from layered radial light, not whitespace alone.

type law. SF Pro Display + SF Pro Text only. hierarchy via weight + size, never via typeface. no serif. no italic. no cursive. ever. one rotated chip max per screen. one signature playful element max.

memoji law. memoji top-right of Topbar, always present, links to /settings/. memoji avatars on People stay. never strip.

creative-reference law. board/ is the standard. every visual decision calibrates from those images.

12 customizable-image affordance

Top-right corner of any card with imagery (Goals, Visions, Wishlist, Habits, People, Routines). 30×30 frosted disc with 14px camera glyph. Hit area extends to the full 44×44 corner zone for fat-finger forgiveness.

vision · 6 months
launch the studio
180 days · momentum holding steady

specs

  • disc: 30×30, 50% radius, rgba(255,255,255,.78) + backdrop-filter: blur(14px) saturate(140%).
  • shadow: inner highlight + 0.5px hairline + 4px ambient drop.
  • glyph: 14×14 lucide-style camera, --ink-2, 1.6 stroke.
  • hit area: 44×44 — extends 7px past the visible disc on all sides.
  • action: opens system photo picker → image is masked into the card's hero region with the existing gradient as fallback.
  • placement: 14px from top, 14px from right. always.

15 don't list · explicit failure modes

  • amber, orange, red, purple, yellow tints (anywhere)
  • bottom-up sheets (use right-drawer or paper-fade)
  • hamburger menus
  • voice-input components (this is a director-executor app, not Siri)
  • full-width desktop cards (always max-width per surface)
  • philosophy verbiage — "microscope", "telescope", "flow state", "deep work" as marketing copy
  • streak-fire emoji 🔥 (use the geometric flame illo instead)
  • confetti, sparkles, celebration explosions
  • hustle copy — "crush it", "grind", "10x", "level up"
  • guilt language — "missed", "behind", "late", "failed"
  • generic productivity tropes (Pomodoro tomato, kanban swim-lanes)
  • icon + text-label bottom navs
  • more than one rotated chip per screen
  • more than one signature/playful element per screen
  • asking the user for color/font preferences (the references decide)
  • Inter, Roboto, Poppins (system stack only)
