anatomy. each routine card carries an identity line (display 18/800), a calm cadence phrase below, an 8-week × 7-day kept-dot grid (filled = kept, hairline = missed, never red, today gets glow ring), and a streak pill in the foot. cover glyph top-right is editable.

cadence kinds. weekly · biweekly · monthlyWeeks · monthlyDays · interval. each kind reveals a different config row (weekday toggles, week-of-month chips 1-5, day-number, interval days). a plain-english phrase derives below in real time.

distinct. habits uses a single 7-day strip + horizontal row treatment. routines uses the full 8×7 grid PER card, identity-led, with the cadence builder being its signature surface. visions is goal-led, no cadence. domains is momentum-word, no grid.
