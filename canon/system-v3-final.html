Do It · system v3-final

playful premium Apple. calibrated from board/. no glass-liquid. no serif. SF Pro Display + SF Pro Text only.

tokens are inlined. every recipe below references the board image it was derived from. layouts vary per screen — system gives the vocabulary, not the composition.

palette law. white page bg (always). accents: pink · green · black · blue. nothing else. red, orange, yellow, purple are forbidden — even in tints. no beige, no cream, no sand as page bg.

shadow law. soft Apple drop shadow, multi-stop, never heavy. --shadow-paper is the default. --shadow-press-ink only on the primary ink button. NO backdrop-filter blur as a defining surface.

type law. SF Pro Display for hero/title (700-800 weight). SF Pro Text for body/eyebrow/label (500-700 weight). Tabular numerics on counts/durations. never serif. never italic. never cursive.

memoji law (LOCKED). 30px circle, top-right of every Topbar. Source = https://www.tapback.co/api/avatar/jay.webp?color=7 EXACTLY (Adam: black hair + black beard + glasses). NEVER substitute a different seed or color. Tap → /settings/. Never stripped.

topbar law. Quote line LEFT = rotating motivational quote (lowercase, period at end, SF Pro Display Semibold). Curated set of ~30. Examples: "discipline equals freedom." / "you become what you repeat." / "today is the lift." / "the mountain doesn't care." / "show up. that's the move." / "quiet work, loud results." / "every rep is a vote." NEVER a personal greeting — "adam. ready when you are." pattern is dead.
